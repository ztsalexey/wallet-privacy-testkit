# Randomized fresh-sender study

This [plan](study-plan.json) is committed before the full data-collection run. It declares all 21 sessions, timing offsets, condition order, and scheduling seeds. The [methodology](../../docs/PRIVACY_STUDY.md) fixes the detector rule, fresh sender requirements, and reporting before evaluation. Results will be added after the full run; this plan alone is not evidence of completion.

Development smoke tests exercise fresh Zingolib and zcash-devtool senders with a separate fixed test seed. Those data are excluded from calibration and evaluation. The full run uses the newly generated seed retained here, with newly generated wallets. The seed is not selected based on detector performance.
